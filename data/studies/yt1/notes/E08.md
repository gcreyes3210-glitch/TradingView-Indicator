# E08 - outside-open reversal (`tools/yt1/s_E08.py`)

## `--check` prints FAIL, by construction; read this first
The order is entered at the 09:30 open (`etype="open"`, signal bar = the bar before 09:30) and its stop is "half the
target distance above the entry", so both the signal and the stop are a function of the 09:30 open. That read is the
exception written in `s_Z00.py`. `core.causal_check` mirrors every price after the signal bar, the 09:30 open
included, so the stop comes out a few ticks different and the test reports a look-ahead on every sample (same number
of orders, same targets, only the stop of the sampled order differs). Nothing else of the future is read. Evidence:
`python3 tools/yt1/s_E08.py` runs the same test on the same 16 samples with one change, the open of the bar right
after the signal bar keeps its true value while that bar's high, low and close and every later bar are mirrored:
16 of 16 identical, PASS. `core.py` was not touched. The rule cannot be coded without that read (a resting order
cannot express "if the open is above X, sell the open"), so it is coded as the spec and `s_Z00.py` say.

## 1. Readings added beyond the spec text (all fixed before the first run)
- Signal bar = the last 1-minute bar before 09:30 on the same calendar day: the 09:29 bar, except 2020-03-09 (09:12)
  and 2020-03-12 (09:24), when the market was halted limit-down before the open.
- Previous RTH high / low = day table `pdh` / `pdl`; daily ATR = day table `atr`. The day table counts holiday
  half-sessions as cash days (for example 2021-05-31, 2022-11-24), so they are traded and they supply the "previous
  RTH range" of the next day. Not altered.
- Target distance = |09:30 open - the level| before slippage. Stop = the open -/+ fraction x that distance, rounded
  to the tick away from the entry (never tighter than the text). Target = the level itself. Otherwise the flat bar.
- "By >= 0.05 x ATR" is tested on the unrounded product.

## 2. Coding errors found after first seeing results
None. The trade code was not changed after its first run; `check_with_true_open` was added after the first `--check`.
