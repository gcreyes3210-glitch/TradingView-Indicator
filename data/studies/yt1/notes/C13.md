# C13 - Connors RSI + 200 MA

Module: `tools/yt1/s_C13.py`. Variants: `base` 5-minute, `nb1` 3-minute, `nb2` 15-minute bars (`bar` parameter).

## 1. Readings added beyond the spec text
- **Connors RSI (3, 2, 100)** is not in `ind.py`; `connors_rsi()` in the module follows TradingView's built-in:
  average of (a) `ind.rsi(close, 3)`, (b) `ind.rsi(streak, 2)` where streak = +n after n consecutive higher closes,
  -n after n lower closes, 0 on an unchanged close, (c) percent rank of the 1-bar rate of change = the percentage of
  the **previous 100** values that are **<= the current one** (TradingView's `ta.percentrank`; Connors' own text
  counts "less than", which differs only on ties). First value at bar 101.
- **"Crosses back above 10"** = CRSI[k] > 10 and CRSI[k-1] <= 10. **"Crosses below 90"** = CRSI[k] < 90 and
  CRSI[k-1] >= 90.
- **Signal window on the neighbours:** open time + N minutes within 09:35 ... 15:00 (3-minute bars opening 09:33 ...
  14:57, 15-minute 09:30 ... 14:45).
- **Swing stop** = lowest low (highest high) of bars k-9 ... k, 1 tick beyond. **Target** = close -/+ 1.5 x
  |close - stop|, `core.tick_round` nearest.
- Every qualifying bar is a candidate order (808: 439 long, 369 short); `run_orders` enforces one at a time.
