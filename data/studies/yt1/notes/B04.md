# B04 - Jooviers Gems London box (`tools/yt1/s_B04.py`)

## 1. Readings added beyond the spec text (all fixed before the first run)
- "Trades outside" (the 09:00-09:29 void test) and "close outside" (the signal) are strict: a high above the box
  high or a low below the box low; a close above the box high or below the box low. A touch of the edge is not
  outside.
- The box is built from whatever 1-minute bars exist in the window (every in-sample day had bars in it).
- Wicks outside the box between 09:30 and the signal bar do not void anything: only the 09:00-09:29 test does.
- 2R target from the signal bar's close (the entry price before slippage), rounded to the nearest tick.
- Neighbours change only the box start (03:00, 05:00); the void test and signal window are unchanged.

## 2. Coding errors found after first seeing results
None. The module was not changed after its first run.
